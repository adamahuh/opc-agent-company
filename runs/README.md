# runs/ — dated audit evidence (append-only)

One directory per measured run: `RUN-001-before/`, `RUN-002-after/`.
Contents per run: engine answers (verbatim excerpts + screenshot refs),
SERP rank dumps, crawler/robots checks, and one `ledger.jsonl` line per
performed action. **This is the 200f the score nobody can argue with,
and the .gitignore must never hide it.**

A run is not "passed" because it produced output — see the proof-level table
in `docs/MEMORY.md §1` (syntax ≠ integration ≠ browser ≠ founder QA ≠ deploy).
